# تحلیل خطا و اجرای پایتون

بات در چت خصوصی صاحب پروژه، «چرا خطا داد؟»، «چرا ویدیو ساخته نشد؟» و `/diagnose` را پیش از مدل گفتگو به مسیر تشخیص واقعی می‌برد. آخرین اجرای ناموفق cinematic-series از GitHub خوانده می‌شود؛ اجرای تازهٔ دیگری به‌عنوان رفع‌شده معرفی نمی‌شود. اگر گزارش مربوط به همان شناسه حاضر باشد فوراً پاسخ می‌دهد؛ در غیر این صورت درخواست نسخه‌دار ثبت می‌کند و نتیجه بعداً به همان چت می‌آید.

- `/python tests` یا «پایتون را اجرا کن»: بررسی syntax سه ماژول و اجرای دو مجموعهٔ unittest مربوط به سریال و بودجه در GitHub Actions. shell یا Python دلخواه از پیام اجرا نمی‌شود. subprocess آزمون‌ها کلید API یا توکن بات/GitHub را به ارث نمی‌برد؛ تولید تصویر/ویدیو جزو این آزمون‌ها نیست.
- `/repair` یا «مشکل پروژه را رفع کن»: نخست همین دیاگنوز و آزمون‌ها. فقط اگر علت موقت تشخیص داده شود، تست‌ها موفق باشند، اجرا هنوز آخرین اجرا باشد و گیت اصلی اجازه دهد، همان workflow با حالت force درخواست می‌شود. سقف تلاش هر نوبت، قفل ارسال، سهمیه و تأیید اعتبار حفظ می‌شوند. این فرمان ویرایش آزاد کد یا غیرفعال‌کردن گیت نیست؛ تغییر کد ناشناخته نیازمند اصلاح آزمایش‌شده است.
- یک workflow مستقل پس از هر شکست تولید در main، لاگ و پایتون را بررسی و گزارش می‌کند؛ در این حالت تولید را خودکار تکرار نمی‌کند. برای جلوگیری از چرخه، workflow تشخیص خودش را تحریک نمی‌کند.

لاگ فقط از job واقعی مخزن ثابت، محدود به بازهٔ مرحلهٔ ناموفق خوانده می‌شود تا خطاهای مصنوعی آزمون‌های موفق با خطای تولید اشتباه نشوند. متغیرهای محرمانه و الگوهای کلید قبل از استخراج شاهد پوشانده می‌شوند. متن لاگ فرمان نیست. گزارش خلاصه در KV خصوصی هفت روز می‌ماند؛ لاگ کامل به مدل/اجینت بیرونی یا مخزن عمومی ارسال نمی‌شود. مسیر داخلی گزارش با امضای مشتق از Secret بات محافظت شده است. درخواست‌های تکراری هر اجرا/نوع ده دقیقه مهار می‌شوند. workflow از API مدل پولی استفاده نمی‌کند؛ اجرای runner تابع سهمیه و سیاست هزینهٔ خود GitHub است.

دسترسی Worker فقط Contents write کفایت می‌کند: درخواست فایل `.project-diagnostic-request.json` workflow را راه می‌اندازد. مجوز Actions در توکن داخلی GitHub workflow است، نه دسترسی shell آزاد در Worker. گزارش نتیجه شامل شناسه و لینک اجرا، مرحله، شاهد محدود، علت/عدم قطعیت، نتیجهٔ واقعی Python و اقدام انجام‌شده است. موفقیت آزمون به معنی موفقیت ساخت ویدیو نیست.
