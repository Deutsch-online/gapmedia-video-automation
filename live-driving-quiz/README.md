# FahrFit — لایو تمرین تئوری رانندگی، فارسی و آلمانی

برنامهٔ مستقل از سری ویدیویی مارتا و لوکاس: صفحهٔ عمودی برای OBS / LIVE Studio، ۱۳ سؤال تألیفی دو‌زبانه با منابع StVO، سه گزینه، سه هدیهٔ قابل‌تنظیم، شمارندهٔ پاسخ، توضیح صحیح و امتیاز آموزشی. فایل‌های منبع قانون همراه زمان بازیابی در `data/legal-sources.json` ثبت‌اند. این سؤال‌ها بانک رسمی TÜV/DEKRA و آزمون رسمی نیستند.

## اجرای روی کامپیوتر شما

Node.js 20 یا جدیدتر را نصب کنید. سپس در همین پوشه:

در Windows فایل `START-WINDOWS.cmd` و در macOS/Linux فرمان `bash start.sh` نصب و اجرا را انجام می‌دهد. روش دستی:

```bash
npm ci --ignore-scripts
npm start
```

ترمینال دو نشانی می‌دهد: `Screen` برای نمایش و `Control` برای پنل خصوصی. نشانی کنترل شامل رمز تصادفی بعد از `#` است؛ آن را روی لایو نشان ندهید. رمز در `.runtime.json` محلی نیز نوشته می‌شود و با هر راه‌اندازی تغییر می‌کند. برای توقف `Ctrl+C` بزنید.

۱. ابتدا پنل خصوصی را باز و یک سؤال آزمایشی شروع کنید. با دکمه‌های A/B/C پاسخ فرضی بدهید و جواب را نمایش دهید. در این حالت هیچ گیفت واقعی ارسال یا ثبت نمی‌شود.

۲. در OBS یک Browser Source با عرض **1080** و ارتفاع **1920** بسازید. URL صفحهٔ نمایش، معمولاً `http://127.0.0.1:4317/screen`، را وارد کنید. در LIVE Studio می‌توانید صفحه را با Browser یا Window Capture نشان دهید.

۳. در حساب دارای دسترسی TikTok LIVE و دریافت Gifts، لایو را از برنامه یا ابزار رسمی خود TikTok روشن کنید. این برنامه دسترسی LIVE ایجاد نمی‌کند و ویدیو/صدا به TikTok ارسال نمی‌کند.

۴. در پنل به `easydeutsches` یا نام حساب خود وصل شوید. پس از دریافت فهرست زندهٔ هدایا، برای A و B و C **سه هدیهٔ متفاوت** انتخاب و ثبت کنید. نام و Coin از همان فهرست می‌آید؛ شناسه و هزینهٔ فرضی فعال نمی‌شوند. اگر حساب لایو نباشد، فهرست دریافت نشود یا اتصال محدود باشد، حالت واقعی فعال نمی‌شود.

۵. «فعال‌سازی پاسخ با گیفت واقعی» را بزنید و سؤال را شروع کنید. پاسخ فقط با هدیهٔ تعیین‌شده ثبت می‌شود. می‌توانید گردش خودکار ۳۰ ثانیه سؤال + ۱۲ ثانیه توضیح را فعال کنید؛ توقف یا قطع اتصال، دریافت پاسخ را متوقف می‌کند.

## قاعدهٔ پاسخ‌ها

- هر هدیه یک گزینه را انتخاب می‌کند، نه یک شانس یا امتیاز اضافی. هدیهٔ دیگر یا هدیهٔ گران‌تر امتیاز بیشتری ایجاد نمی‌کند.
- در سؤال تک‌پاسخی، اولین انتخاب هر بیننده ثبت می‌شود. ارسال هدیهٔ دیگر انتخاب را عوض نمی‌کند؛ این قاعده روی صفحه گفته می‌شود.
- در سؤال چندپاسخی، هدایای گزینه‌های مختلف انتخاب‌ها را جمع می‌کنند؛ برای مثال A و B. فقط مجموعهٔ دقیق پاسخ‌های درست یک امتیاز دارد. برای انتخاب هر سه گزینه، می‌توان یک هدیهٔ چهارمِ جدا با عنوان «هر سه» تعیین کرد؛ ارسال همان یک هدیه هر سه پاسخ را انتخاب می‌کند. اگر تنظیم نشود، هدایای سه گزینه انتخاب‌ها را جمع می‌کنند.
- هدیهٔ زنجیره‌ای پس از پایان زنجیره فقط یک بار خوانده می‌شود. پیام تکراری، هدیهٔ ناشناخته و هدیهٔ دیررس وارد سؤال بعد نمی‌شود. برنامه هیچ بازپرداختی از طرف TikTok انجام نمی‌دهد؛ ارسال بعد از پایان زمان ممکن است هزینه داشته باشد ولی پاسخ ثبت نمی‌شود.
- امتیازها آموزشی‌اند؛ جایزهٔ نقدی، قرعه‌کشی یا تضمین قبولی وجود ندارد. قیمت نهایی هدیه در رابط خود TikTok تعیین می‌شود.

## محدودیت اجرا و هزینه

کد به‌صورت محلی و فقط روی `127.0.0.1` اجرا می‌شود. برای کار دائمی، کامپیوتر/سرور Node.js باید روشن بماند؛ Cloudflare Worker فعلی جای سرور پایدار Node.js با این کتابخانه نیست. در این نسخه اتصال به بات تلگرام یا سرویس میزبانی دائمی ساخته نشده است. نام کاربری کافی است؛ رمز، session cookie، OAuth token یا کلید پولی Euler Stream دریافت نمی‌شود. اتصال غیررسمی و محدودیت سرویس واسط ممکن است باعث خطا شود؛ مسیر پولی خودکار ندارد. ارسال هدیه برای بیننده می‌تواند هزینه داشته باشد.

پاسخ‌ها و جدول امتیازها در حافظه‌اند و با راه‌اندازی مجدد پاک می‌شوند. برنامه دادهٔ خام حساب‌ها را در GitHub ذخیره نمی‌کند. فایل تنظیم هدایا محلی است و در Git ثبت نمی‌شود. برای اضافه‌کردن سؤال، ساختار `data/questions.json` را با سه گزینه و کلید `correct` رعایت و منبع معتبر به‌روز تعیین کنید.

```bash
npm test
```
