# بررسی Runtime برای پروژه — ۲۰۲۶-۱۰-۲۹

## نتیجه

Runtime برای محیط ایزولهٔ کدنویسی، اجرای تست، پردازش فایل و رندر CPU با FFmpeg گزینهٔ قابل‌بررسی است. مستندات رسمی تصریح می‌کنند sandboxها روی CPU اجرا می‌شوند؛ در تنظیمات ساخت sandbox در SDK نیز GPU/CUDA ارائه نشده است. بنابراین جایگزین تأییدشده‌ای برای GPU مدل گفتاری فعلی پروژه و رفع محدودیت سهمیهٔ لب‌خوانی نیست.

پردازش CPU و آزمون‌های این پروژه در محیط فعلی و GitHub Actions اجرا شده‌اند؛ برای رفع مانع کنونی، افزودن یک تأمین‌کنندهٔ CPU دیگر مزیت اثبات‌شده‌ای ندارد. Runtime به‌عنوان مرجع بررسی‌شده ثبت شد؛ backend، کلیدها و زمان‌بندی فعلی تغییر نکردند.

## شرایط رایگانِ تأییدشده در مستندات عمومی

| مورد | شرایط منتشرشده |
| --- | --- |
| حافظه | ۱۰۰ GiB-hour |
| پردازندهٔ فعال | ۲۵ vCPU-hour |
| حسابی که پرداخت نکرده | یک‌بار در ۳۰ روز اول؛ ماندهٔ زمان ماشین پس از این مهلت تمام می‌شود |
| تمدید ماهانه | برای حسابی که قبلاً اعتبار خریده؛ اول ماه UTC |
| هم‌زمانی بدون اعتبار | تا چهار sandbox |
| حداکثر هر sandbox بدون اعتبار | ۲ vCPU، چهار GiB RAM، ده GiB دیسک |
| ورود | ورود تأییدشده؛ برای استفادهٔ CLI/MCP تأیید اتصال در مرورگر لازم است |
| ثبت حساب از دیتاسنتر یا VPN | طبق شرایط، سهمیهٔ رایگان پس از افزودن اعتبار ارائه می‌شود |
| فراخوانی مدل‌های AI | جزو سهمیه نیست |
| پس از پایان سهمیه در حساب دارای اعتبار | مصرف از اعتبار پیش‌پرداخت ادامه پیدا می‌کند؛ انتخاب funding=trial تضمین رایگان‌ماندن نیست |

۱۰۰ GiB-hour، ظرفیت RAM صد گیگابایتی نیست: مثلاً چهار GiB حافظه برای ۲۵ ساعت این سهمیهٔ حافظه را مصرف می‌کند؛ سهمیهٔ CPU جداست و ممکن است زودتر تمام شود.

CLI، MCP و SDKهای JavaScript، Python، Go، Ruby و Java در مستندات و مخزن رسمی معرفی شده‌اند. Docker داخل sandbox، SSH، فایل و اجرای فرمان مستند هستند. برخی امکانات شبکه، نگهداری و زمان‌بندی به اعتبار یا پرداخت قبلی وابسته‌اند؛ رایگان‌بودن تمام قابلیت‌ها نتیجه نمی‌شود.

## وضعیت بررسی و استفاده

- صفحهٔ رسمی، قیمت‌گذاری منتشرشده، راهنمای سهمیه و انتخاب sandbox از شبکهٔ GitHub Actions خوانده شدند؛ پاسخ HTTP 200 بود. ابزار وبِ این جلسه محتوای text/markdown را پشتیبانی نکرد.
- README و بخش‌های مرتبط SDK و راهنما در مخزن رسمی بررسی شدند.
- هیچ حساب یا sandboxی ایجاد نشد؛ اتصال احراز‌شدهٔ Runtime در ابزارهای این جلسه وجود ندارد. اجرای واقعی پروژه روی Runtime و ادعای بهبود سرعت/هزینه آزمایش نشده‌اند.
- انتقال خودکار کل پروژه، پرداخت USDC، افزودن اعتبار و ارسال feedback که در متن سایت پیشنهاد شده‌اند، جزو درخواست صاحب پروژه نیستند و اجرا نشدند.
- برای استفادهٔ آیندهٔ CPU: ابتدا ورود صاحب حساب و وضعیت واقعی سهمیه و محدودیت هزینه بررسی شود؛ یک کار واقعی محدود مانند تست‌های همین پروژه اجرا و خروجی و exit code بررسی شود؛ پس از کار sandbox حذف شود. کلیدهای پروژه در چت یا مخزن قرار نمی‌گیرند.
- مجوز مصرف اعتبار پولی برای تکمیل ویدیوی داکتر همچنان داده نشده است؛ این بررسی آن مجوز را ایجاد نمی‌کند.
