Question bank sources / منابع بانک سؤال

The arithmetic questions are generated locally from fixed, distinct expressions. The additional factual questions use the frozen data sources below. Country facts were adapted into bilingual capital, ISO-code and continent questions; element names and atomic numbers were adapted into bilingual multiple-choice questions. The application does not fetch new factual answers automatically.

  • mledoze/countries — country names, ISO codes, capitals and continents. The derived geography question database is available under the Open Database License 1.0.
  • Bowserinator/Periodic-Table-JSON, with information from Wikipedia — confirmed element names and atomic numbers 1–118. The adapted element questions are available under Creative Commons Attribution-ShareAlike 3.0 Unported. See the source license notice.

No author or data source endorses this application. Only names and factual fields were used; no element illustrations or Wikipedia prose were copied.
