# Aryana LIVE Studio

A standalone Persian/Dari and English virtual host. Public output: `/live` for 1080×1920 OBS/TikTok Studio sources, `/mobile` for mobile playback. Owner controls require the private management key.

The accepted scene uses natural-looking prepared video of Aryana in the original frontal chair framing. No still image, video poster or 3D character appears in the public player. The muted waiting video loops; prepared welcome and thanks clips play with their original audio, then return to the waiting video. Fresh conversational responses are audio-only, without newly generated lip animation.

Entry welcomes say “سلام، خوش آمدید!”; recognized names retain personalized welcomes and known guests above level 25 receive the respectful greeting. Gifts and likes say only “بسیار تشکر!”. Numeric or unrecognized names are never spoken. Public output contains only the `KI-Generated` label.

Refresh the browser source once after a player update. Tap the player once to unlock audio. Connect the actual active TikTok username in the private panel; opening the scene URL alone does not start a TikTok broadcast.

Prepared GPU videos used verified included Hugging Face PRO quota only. The measured 83–88 seconds per short generation is unsuitable for generating each LIVE response in real time. Production hosting remains CPU basic and does not automatically request GPU generation or paid credits. Private voice profiles and management credentials are not published.
